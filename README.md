# GOL'26 - 8th International Conference on Logistics Operations Management

Welcome to the official repository for the **GOL'26** conference website. This project is a modern, responsive web application designed for the 8th International Conference on Logistics Operations Management, held in **Fez, Morocco**, from **May 7th to 9th, 2026**.

## 🌐 Live Preview
The site is optimized for static hosting platforms like **GitHub Pages**.

## ✨ Features
- **Modern Design**: Premium glassmorphism aesthetic using a professional purple, pink, and black color scheme.
- **Responsive Layout**: Fully optimized for desktops, tablets, and mobile devices.
- **Dynamic Countdown**: Live timer counting down to the conference start date.
- **Comprehensive Sections**:
    - **Home**: Overview and indexing information.
    - **Speakers**: Profiles of keynote and invited speakers.
    - **Sponsors & Partners**: Recognition of conference supporters.
    - **Author Guidelines**: Manuscript templates and submission instructions.
    - **Committees**: List of organizing and scientific committee members.
    - **Venue**: Information about Fez, Morocco, including travel tips and gallery.
    - **Registration**: Details on fees and payment methods.

## 📂 Project Structure
The project is organized into dedicated directories for better maintainability and GitHub Pages compatibility:

```text
├── index.html                  # Homepage
├── author-guideline.html        # Guidelines for authors
├── committees.html              # Committee members
├── keynote-speakers.html        # Speaker profiles
├── registration-fees.html       # Fee details
├── special-sessions.html        # Call for special sessions
├── sponsor-and-partners.html    # Sponsors list
├── venue.html                  # Location & Gallery
├── css/
│   └── style.css               # Main stylesheet (Glassmorphism & Layout)
├── js/
│   └── script.js                # Interactive logic (Countdown, Tabs, Navigation)
├── images/                      # Website assets (Logos, Photos, Backgrounds)
└── docs/                        # Downloadable documents (Templates, CFP, RIB)
```

## 🛠️ Technologies Used
- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, Flexbox/Grid layouts, and glassmorphism effects.
- **JavaScript**: Vanilla JS for interactivity (no heavy dependencies).
- **Google Fonts**: "Outfit" for a modern typographic feel.
- **FontAwesome**: High-quality icons for better UX.

## 🚀 Deployment to GitHub Pages
To host this project on GitHub Pages:
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, select the `main` branch and the root `/` folder.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repository-name>/`.
